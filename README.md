# Commed8_Maps

ต้นแบบหน้าแผนที่เดินดิน (COMMED 69 เขต 8 บ้านบึงสวาง หมู่ 11) สำหรับทดลองปักหมุดบ้านและใส่รายละเอียดบนภาพดาวเทียม

- **ข้อมูลทั้งหมดเป็นข้อมูลสมมติ** หมุดบ้านในโหมดตัวอย่างไม่ใช่บ้านจริง
- ที่ปักหมุดหรือแก้ไขเก็บไว้ในเบราว์เซอร์ของผู้ใช้แต่ละคนเท่านั้น (localStorage) ไม่ส่งไปที่ใด
- `?real=1&z=18` แสดงภาพดาวเทียมของพื้นที่ตามพิกัดอ้างอิงในคู่มือฝึกภาคสนามร่วมฯ 2569 โดยไม่มีหมุดบ้าน
- ห้ามนำข้อมูลบ้านรายหลังหรือข้อมูลสุขภาพจริงมาใส่ใน repo สาธารณะนี้

## ศูนย์รวมวิถีชุมชน · `workspace-demo/`
หน้าเว็บศูนย์รวมวิถีชุมชนทั้ง 6 วิถี: ส่งโน้ต คลังกลาง ถาดหัวหน้าวิถี ที่เลือกเก็บไว้ แผนที่เดินดิน และบุคคล พร้อมค้นหากลาง ระบบเสนอให้ผูกบ้านเลขที่/ชื่อคน และปิดชื่อตอนส่งออก

มี 2 โหมด
- **โหมดตัวอย่าง** (เปิดหน้าเว็บเฉยๆ) ใช้ข้อมูลสมมติ เก็บในเบราว์เซอร์ของแต่ละคนเท่านั้น
- **โหมดเชื่อมต่อ** กด ⚙️ ใส่ที่อยู่เซิร์ฟเวอร์ (Web app URL) กับรหัสส่วนตัว ข้อมูลจะซิงค์กับ Google Sheet และรูปเก็บใน Google Drive ของทีม ที่อยู่และรหัสเก็บเฉพาะในเบราว์เซอร์เครื่องนั้น ไม่อยู่ในโค้ด

### ตั้งค่าเซิร์ฟเวอร์ (หัวหน้าทีมทำครั้งเดียว)
1. ไปที่ script.google.com สร้างโปรเจกต์ใหม่ วางโค้ดจาก `workspace-demo/apps_script/Code.gs`
2. เลือกฟังก์ชัน `setup` แล้วกด Run (อนุญาตสิทธิ์) จะสร้าง Google Sheet กับโฟลเดอร์รูปให้ รหัสผู้ดูแลชุดแรกอยู่ในชีต `access` คอลัมน์ `code`
3. Deploy → New deployment → Web app → Execute as **Me** → Who has access **Anyone** (ทุกคำขอต้องมีรหัสที่อยู่ในชีต `access`) แล้วคัดลอก URL ที่ลงท้าย `/exec`
4. เปิดหน้าเว็บ กด ⚙️ ใส่ URL กับรหัสผู้ดูแล จากนั้นสร้างรหัสให้คนอื่น (สมาชิก / หัวหน้าวิถี 1-6 / ผู้ชม) ได้จากหน้าตั้งค่า ไม่ต้อง Deploy ใหม่

สิทธิ์ตามบทบาทบังคับที่เซิร์ฟเวอร์: ผู้ชมแก้ไม่ได้ · สถานะรายวิถีเปลี่ยนได้เฉพาะหัวหน้าวิถีนั้นหรือผู้ดูแล · แก้ข้อความได้เฉพาะเจ้าของโน้ตหรือผู้ดูแล · แก้ข้อมูลเดียวกันพร้อมกันจะแจ้งเตือนและใช้ฉบับล่าสุดของเซิร์ฟเวอร์

### เชื่อมกับแอปแบบสอบถาม (ไม่บังคับ)
ในหน้าตั้งค่าใส่ที่อยู่ Apps Script ของแอปแบบสอบถามกับรหัสทีม ระบบใช้คำสั่ง `house` ที่มีอยู่แล้ว (อ่านอย่างเดียว) เพื่อติ๊ก "สัมภาษณ์แล้ว" ให้บ้านบนแผนที่ ไม่ต้องแก้ฝั่งแบบสอบถาม ค่านี้เก็บเฉพาะในเครื่องที่ตั้ง
