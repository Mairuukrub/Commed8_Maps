# Commed8_Maps

ต้นแบบหน้าแผนที่เดินดิน (COMMED 69 เขต 8 บ้านบึงสวาง หมู่ 11) สำหรับทดลองปักหมุดบ้านและใส่รายละเอียดบนภาพดาวเทียม

- **ข้อมูลทั้งหมดเป็นข้อมูลสมมติ** หมุดบ้านในโหมดตัวอย่างไม่ใช่บ้านจริง
- ที่ปักหมุดหรือแก้ไขเก็บไว้ในเบราว์เซอร์ของผู้ใช้แต่ละคนเท่านั้น (localStorage) ไม่ส่งไปที่ใด
- `?real=1&z=18` แสดงภาพดาวเทียมของพื้นที่ตามพิกัดอ้างอิงในคู่มือฝึกภาคสนามร่วมฯ 2569 โดยไม่มีหมุดบ้าน
- ห้ามนำข้อมูลบ้านรายหลังหรือข้อมูลสุขภาพจริงมาใส่ใน repo สาธารณะนี้

## ศูนย์รวมวิถีชุมชน (ต้นแบบ 3.2) · `workspace-demo/`
ต้นแบบหน้าศูนย์รวมวิถีชุมชนทั้ง 6 วิถี: ส่งโน้ต คลังกลาง ถาดหัวหน้าวิถี ที่เลือกเก็บไว้ แผนที่เดินดิน และบุคคล พร้อมค้นหากลางและระบบเสนอให้ผูกบ้านเลขที่/ชื่อคน

- **ข้อมูลทั้งหมดเป็นข้อมูลสมมติ** ชื่อคนและบ้านเลขที่ในตัวอย่างไม่ใช่ของจริง
- ข้อมูลที่กรอกเก็บในเบราว์เซอร์ของแต่ละคนเท่านั้น ยังไม่ต่อ Google Sheet/Drive และยังไม่มีรหัสเข้าใช้
- เวอร์ชันใช้งานจริงจะเก็บข้อมูลใน Google Sheet/Drive ส่วนตัวของทีม ห้ามนำชื่อหรือข้อมูลรายบ้านจริงมาใส่ใน repo สาธารณะนี้
